# Home Assistant Hermes Agent Repository

Official Home Assistant App repository for **Hermes Agent**.

## Features

- **Google Gemini 3.6 Integration**: Control Home Assistant using Gemini API and Telegram bot
- **Hermes Desktop Remote Control**: SSH/SFTP workspace access on port 2223
- **Safe YAML Backups & History**: Automatic backups under /config/hermes/backups/ and 12-month change history
